# Outreach OS

Autonomous email outreach system for Plarix. Four-node pipeline:

- **SIGNAL** — Recursive graph discovers signals anywhere on the internet
- **RESEARCH** — Per-lead deep research with dual-track discovery, evidence grading
- **CRAFT** — Offer builder from user-defined templates, no LLM hallucination
- **SEND** — (deferred)

Built on LangGraph + Postgres + FastAPI + React.
